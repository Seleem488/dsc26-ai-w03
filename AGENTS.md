
# AGENTS.md — Tawseel

## Project Overview
- This project predicts failed Cash-on-Delivery parcel deliveries.
- Follow the existing project structure and interfaces.

## Environment
- Python version: 3.12.
- Dependencies are managed with uv.
- Do not modify pyproject.toml dependencies or uv.lock without approval.
- Install dependencies using `uv sync`.
- Run tests using `uv run pytest`.

## Project Structure
- `tawseel/data.py`: synthetic parcel data generator; do not modify.
- `tawseel/model.py`: feature engineering, preprocessing and ML models.
- `tests/test_public.py`: public test suite.
- `RESULTS.md`: model evaluation results and business summary.
- `AI_USAGE.md`: AI tools and code review record.
- `pyproject.toml`: project configuration.

## Data Rules
- Use synthetic data generated by `tawseel.data.make_parcels`.
- Never use `courier_notes` as a prediction feature.
- Never use `delivered_at` as a prediction feature.
- Never use `failed` as an input feature.
- Never use `parcel_id` as a prediction feature.
- Preserve point-in-time correctness when creating customer history.
- Parcels with identical timestamps must not count as prior events.

## Machine Learning Rules
- Use only information available when a parcel is created.
- Use chronological train/test splitting.
- Keep preprocessing inside the sklearn Pipeline.
- Handle missing values and unseen categories.
- Compare model performance against DummyClassifier(strategy="prior").
- Evaluate ROC-AUC, PR-AUC and Brier score.
- Set random seeds for reproducible experiments.
- Do not claim unusually high performance without investigating leakage.

## Model Development
- Keep feature engineering and model logic in `tawseel/model.py`.
- Preserve the required public function signatures.
- Ignore unrelated input columns.
- Do not fit preprocessing on test data.
- Train models using training data only.

## Before Submitting
- Run `uv run pytest`.
- Check that no post-delivery information leaks into features.
- Update `RESULTS.md` with actual evaluation metrics.
- Update `AI_USAGE.md` with actual tools and corrections.
- Never commit API keys, credentials or personal data.
